HMM Homologue Finder — How to Run

Discover distant protein homologues via profile HMMs + six-frame search. Runs on macOS, Linux, and Windows (WSL2).

⚡ Fastest path: open a terminal in the project folder and run bash start.sh — it walks you through everything (FASTA, databases, options) and runs it for you.
📖 For the full reference — every flag, the method, outputs, tool versions, and a live command builder — see the interactive guide.html.

Run on Windows via WSL2

1

Open Ubuntu (Start menu → “Ubuntu”, or run wsl in PowerShell).

2

Go to the project folder:

cd "/mnt/c/Users/<your-windows-user>/hmm-homologue-finder"
3

Build the environment first time only

bash setup.sh
4

Run the guided launcher (recommended):

bash start.sh

…or a quick smoke test to confirm everything works:

bash run.sh --fasta examples/example_seeds.fasta --smoke
5

Real run on your own seeds (pick databases interactively):

bash run.sh --fasta /mnt/c/Users/<your-windows-user>/my_seeds.faa \
            --name MyFamily --email you@inst.edu --pick-databases --cpu 12
Your Windows C:\ drive is /mnt/c/ in WSL. Keep the seed FASTA under C:\ so both sides can see it.

Run natively on macOS (no WSL)

1

Install Miniforge (conda) and git first time only — easiest via Homebrew:

brew install miniforge git

No Homebrew? Use the official installer:

curl -L -O https://github.com/conda-forge/miniforge/releases/latest/download/Miniforge3-MacOSX-$(uname -m).sh
bash Miniforge3-MacOSX-$(uname -m).sh
# then close & reopen Terminal
2

Clone the project and enter it:

git clone https://github.com/mbaffour/hmm-homologue-finder.git
cd hmm-homologue-finder
3

Build the environment first time only (≈10–30 min):

bash setup.sh
4

Guided run, or a quick smoke test:

bash start.sh
# or:
bash run.sh --fasta examples/example_seeds.fasta --smoke
5

Real run on your own seeds (native paths — no /mnt/c):

bash run.sh --fasta ~/Desktop/my_seeds.faa \
            --name MyFamily --email you@inst.edu --pick-databases --cpu 8
Apple Silicon (M-series): if setup.sh can’t solve the environment, force Intel builds (run under Rosetta) once: 
CONDA_SUBDIR=osx-64 bash setup.sh

Options

FlagWhat it does
--fasta FILESeed protein FASTA (required for a run)
--name LABELOutput folder label (default: from the FASTA name)
--pick-databasesInteractively choose which databases to search
--list-databasesPrint the database catalog (sizes & est. times) and exit
--databases "A,B"Search specific databases by exact name
--iterations NSearch rounds (default 3)
--cpu NThreads (start.sh auto-detects your cores)
--prodigal-gateStrict: also require Prodigal coding-locus overlap (higher specificity)
--db-cache DIRPersistent DB cache shared across runs (default ~/.cache/hmm-homologue-finder) — each DB downloads once, ever
--smokeFast self-test: 1 iteration on 1 small DB
--out-dir DIRCustom output location

What you get

Everything lands in <name>_discovery/:

PathContents
PACKAGE/The deliverable: hits TSV, sequences, GFF3, GenBank, synteny figures, tree, HMM profile
METHODS.mdManuscript-ready methodology: tool versions, command, params, input checksum, database provenance
run_manifest.jsonMachine-readable record of the whole run
pipeline.logFull run log
run1/ run2/ …Per-iteration validated hits + per-DB reproducibility reports
Speed tips: pick only the databases you need, raise --cpu, and rely on the shared --db-cache so big databases download only once across all your runs.
